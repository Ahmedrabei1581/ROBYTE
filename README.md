# ROBYTE · AI Battlegrounds (Language Schools Edition)

A fast-paced 2D cyberpunk educational action-adventure game built for **Egyptian Baccalaureate 2nd Year — Language Schools (Programming & Artificial Intelligence Curriculum)**, transforming official assessments into high-speed arena combat.

## Key Features

- **4 Progressive Curriculum Worlds:**
  1. **AI Metropolis** — Information Technology & Society
  2. **Cyber Fortress** — Cybersecurity & Network Defense
  3. **Web Realm** — Web Applications Architecture & Communication
  4. **UX Kingdom** — Web & Media Design, Usability & Continuous Improvement
- **20 Sub-Stages & Boss Battles:** 5 escalating stages per world with enemy turrets, barricades, laser deflection, and unique world bosses.
- **100 Official Curriculum Challenges:** 25 assessment questions per world with instant explanations, error diagnostics, and an **80% Mastery Gate (20/25)** to unlock the next world.
- **Seamless In-Place Progression:** Immediately after answering any question, players resume right from their **exact position**, camera view, score, and cleared stage progress without resetting to the start—with movement keys safely reset and shield recharged (`+45`) on correct answers.
- **Secure Player Access & Mobile Activation:**
  - **2-Step First-Time Registration:** Enforces unique usernames (blocking duplicates in Step 1) and generates a 4-digit activation code with direct **WhatsApp** and **SMS App** delivery buttons, plus an offline on-screen code and auto-fill option.
  - **Returning Player Device Dropdown:** Select any registered hero saved on the device, verify the mobile number, and jump straight to the saved World, Sub-Stage, and Screen checkpoint—or use **New Beginning** to restart from World 1 · Stage 1.
- **Offline PWA & Multi-Device Controls:**
  - Installable Progressive Web App (PWA) for full-screen offline play.
  - Supports multi-touch mobile joystick, smart magnetic targeting, keyboard + mouse, and Gamepad API.
- **Teacher & Student Analytics Dashboard:** Mastery tracking, weak-topic diagnostics, and JSON progress report export.
