## Protecting Your Rights on GitHub & GitHub Pages

1. **Proof of Creation on GitHub:**
   - Committing the project to a private or public GitHub repository creates an immutable timestamp and cryptographic `SHA-1` hash establishing priority of authorship.
   - Keeping the repository **Private** protects the source code while retaining full ownership details in `LICENSE`.

2. **Proprietary License (`LICENSE`):**
   - The `LICENSE` file in the root directory explicitly reserves all rights (`All Rights Reserved`) and prohibits unauthorized redistribution, rebranding, or commercial streaming.

3. **Embedded Copyright Notices:**
   - `<meta name="copyright">` and `<meta name="author">` tags are embedded in `index.html`.
   - Visible copyright attribution is rendered in the game title footer and options drawer.

4. **DMCA Protection:**
   - Unauthorized clones or distributions can be removed using a formal DMCA Takedown Notice citing the original commit history and `LICENSE`.
